4. Keep the novelty claim modest and, if later practical, compare the same task with laptop notes. No timing or comfort advantage should be asserted without measurement.
5. Before authorized publication, inspect the exact public files/history, verify licensing/disclosures, complete participant reflections and recheck official submission requirements.
