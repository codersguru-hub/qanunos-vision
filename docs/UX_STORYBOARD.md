# QanunOS Vision: draft rehearsal storyboard

Status: planning only, not an official plan-lens output and not evidence of a working Lens.

## Experience
The participant rehearses a fictional Egyptian oral argument in their own space. No other person is recorded or identified. A clearly labeled mock-question button starts the prepared exchange. Speech recognition is outside the first slice.

Place one small cue near the rehearsal desk and slightly below eye level, with large interaction targets. Do not cover the mock judge's face. World placement, distance and readable type sizes must be tested in the actual preview. Black may render transparent on the additive display; the platform's existing matte-black web design cannot simply be copied into glasses.

## State sequence
1. Ready: "Simulated hearing — fictional facts" and a large prepared-question trigger.
2. Question: one concise mock judicial question; optional argument timeline remains secondary.
3. Rejected: the intentional fictional authority fails identity/provenance checks. Show "Unverified — do not cite"; never label it expired without evidence.
4. Replacement: show a genuinely reviewed authority only when its exact excerpt, source identity and supporting evidence have been curated. If none is available, abstain visibly.
5. Source: select the authority to inspect its original reference and verification state in a spatial detail card. Do not promise an external browser inside the Lens without testing support.
6. Return: dismiss source details and recover an unobstructed rehearsal view.

## Proposed completion checks
- Triggering the prepared question changes the visible rehearsal state.
- An unsupported fixture cannot acquire a verified badge or become the displayed authoritative answer.
- Selecting a source reveals its matching ID, title/reference and reviewed excerpt; missing effective dates remain unknown.
- Dismiss returns to the rehearsal without long scrolling or navigation menus.
- A fresh preview run reproduces the same sequence without a production QanunOS login.

These are draft checks for the real plan-lens discussion and later LEAF/visual tests. None has passed yet.
